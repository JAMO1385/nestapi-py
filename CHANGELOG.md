# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-03

### Added

- `NestApi` sync client with dynamic routing from method names.
- `AsyncNestApi` async client with the same routing, parameters and errors.
- Read-only `Response` with dot-path `get()` and item access.
- Typed exceptions mapped from the API's `error.code`.
- `py.typed` marker for type checkers.
